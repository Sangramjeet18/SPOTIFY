<p>About

This project is a Spotify-inspired music streaming web application developed using HTML, CSS, and JavaScript. It recreates the look and feel of a modern music platform by providing an intuitive interface, music playback controls, playlist management, and a responsive design that works across different devices.

Features
Modern Spotify-inspired UI
Music playback controls (Play, Pause, Next, Previous)
Interactive playlist navigation
Responsive design for desktop and mobile devices
Smooth user experience
Clean and organized code structure
Technologies Used
HTML5
CSS3
JavaScript (Vanilla JS)
Learning Objectives

This project was built to strengthen frontend development skills, improve JavaScript event handling, and practice creating real-world user interfaces inspired by popular applications.
